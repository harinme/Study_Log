# 품질 검토 및 분산 데이터베이스

## CRUD

- 프로세스와 데이터 사이의 의존 관계 표현
- Create(생성), Read(읽기), Update(갱신), Delete(삭제)

## 옵티마이저

- SQL 처리 흐름 구문 분석 → 실행 → 인출
- 구분
  - 규칙 기반: 규칙(우선 순위) 기반
  - 비용 기반: 통계정보 사용

## DBMS 구성요소

- DDL 컴파일러: 스키마 정의문을 분석하고 검증
- DML 프리컴파일러: 프로그램 언어 내부의 SQL문을 찾아 분석
- DML 컴파일러: 데이터 조작어 문장을 분석
- 런타임 데이터 베이스 처리기: 실행 계획을 실제로 수행
- 트랜잭션 관리자: 트랜잭션의 상태 관리

## 분산 데이터베이스

- 구성요소: 분산 처리기, 분산 데이터베이스, 네트워크
- 투명성: 위치, 분할, 지역사상, 중복, 병행, 장애

## **트랜잭션** \*

- 연산을 수행하는 하나의 논리적 다ㅏㄴ위
- 명령어: COMMIT, ROLLBACK, SAVEPOINT
- 트랜잭션의 성질 \* **ACID**
  - 원자성: 모두 수행되거나 모두 수행되지 않아야 함
  - 일관성: 수행 전후의 상태가 일관된 상태 유지
  - 독립성/ 격리성: 트랜잭션 간에 간섭이 없어야 함
  - 영속성/지속성: 트랜잭션의 결과는 영구히 보존되어야 함
  - 트랜잭션의 상태: 활동, 실패, 철회, 부분완료, 완료
