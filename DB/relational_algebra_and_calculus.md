# 관계대수

## 1. 관계대수의 개념

- 데이터를 찾는 절차를 정의하는 절차적 언어
- 데이터를 어떻게 찾을 것인지 명시하며, 처리 과정(연산 절차)을 구체적으로 기술함
- 연산의 피연산자와 결과가 모두 릴레이션(테이블)임
- 일반적인 집합 연산과 데이터베이스 특화된 순수 관계 연산으로 구분됨

#### 4. DIVISION \*\*

- 기호: ÷(나누기)
- 표기법: R÷S
- 예시

  [R]

  |  A  |  B  |

  | a2  | b1  |
  | a2  | b3  |

  [S1]

  |  B  |
  | :-: |
  | b1  |

  [결과]

  |  A  |
  | :-: |
  | a1  |
  | a2  |

  2: (R) ÷ (S2)

  [R]

  |  A  |  B  |
  | :-: | :-: |
  | a1  | b1  |

  | a2  | b1  |
  | a2  | b3  |

  [S2]

  |  B  |
  | :-: |
  | b1  |
  | b2  |

  [결과]

  |  A  |
  | :-: |
  | a1  |

# 관계해석

## 1.관계해석의 개념

- 관계 데이터 모델의 창시자 코드(E.F.Codd)가 제안한 개념으로 수학의 술어 해석(Predicate Calculus)에 기반을 둠
- `비절차적 언어`로, 데이터를 어떻게 찾을지가 아니라 무엇을 찾을지를 정의함
- 튜플 관계해석과 도메인 관계해석이 있음
- 관계해석과 관계대수는 처리 능력 면에서 동등하며, 원하는 데이터를 모두 표현할 수 있음

| 정량자 |  ∃   | 어떤 튜플 하나라도 존재    |
