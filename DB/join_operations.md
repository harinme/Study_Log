# JOIN 연산

## 1. JOIN의 개념

- 두 개 이상의 테이블을 결합하여 데이터를 검색하는 연산
- 관련된 컬럼을 기준으로 서로 연관된 행(Row)을 결합
- 보통 기본키(PK)-외래키(FK) 관계를 기준으로 조인이 수행됨
- 조인의 대상 테이블은 2개 이상도 가능하며, 조인 방식에 따라 결과가 달라짐

## 2. JOIN의 종류

### (1) 내부 조인(Inner Join)

- 두 테이블에서 **공통**되는 데이터만 반환함
- 조인 조건을 만족한 행만 결합됨
- 가장 많이 사용되는 조인 방식임

- 예시
  <details>

  **[회원정보]**

  | 회원번호 |  이름  |
  | :------: | :----: |
  |   0001   | 이홍직 |
  |   0002   | 홍길동 |
  |   0003   | 이창훈 |
  |   0004   | 정광호 |

  **[주문]**

  | 주문번호 | 회원번호 | 상품  |
  | :------: | :------: | :---: |
  |   O_01   |   0001   | 상품1 |
  |   O_02   |   0001   | 상품2 |
  |   O_03   |   0003   | 상품1 |
  |   O_04   |   0004   | 상품  |

  ```sql
  SELECT * FROM 회원정보 INNER JOIN 주문 ON 회원정보.회원번호 = 주문.회원번호;
  ```

  [결과]

  | 회원번호 |  이름  | 주문번호 | 회원번호 | 상품  |
  | :------: | :----: | :------: | :------: | :---: |
  |   0001   | 이홍직 |   O_01   |   0001   | 상품1 |
  |   0001   | 이홍직 |   O_02   |   0001   | 상품2 |
  |   0003   | 이창훈 |   O_03   |   0003   | 상품1 |
  |   0004   | 정광호 |   O_04   |   0004   | 상품  |

  </details>

### (2) 자연 조인(Natural Join)

- 두 테이블에서 동일한 이름, 데이터 타입을 가진 컬럼으로 자동으로 조인함
- 조인 조건을 명시하지 않아도 됨
- 공통 컬럼은 결과에서 한번만 표시됨
- 공통 컬럼의 데이터 타입이 다르면 오류가 발생함
- 예시
  <details>

  **[R1]**

  | COL1 | COL2 |
  | :--: | :--: |
  | 001  |  A   |
  | 001  |  B   |
  | 002  |  B   |
  | 003  |  C   |

  **[R2]**

  | COL2 | COL3 |
  | :--: | :--: |
  |  B   | B001 |
  |  C   | C001 |

  ```sql
  SELECT * FROM R1 NATURAL JOIN R2;
  ```

  [결과]

  | COL2 | COL1 | COL3 |
  | :--: | :--: | :--: |
  |  B   | 001  | B001 |
  |  B   | 002  | B001 |
  |  C   | 003  | C001 |

  </details>

### (3) 전체 외부 조인(Full Outer Join)

- 좌측, 우측 테이블의 모든 행을 포함함
- 공통 데이터는 하나로 결합하여 표시됨
- 한쪽에만 존재하는 행은 다른 쪽 컬럼이 NULL로 표시됨
- 예시
   <details>

  **[R1]**

  | COL1 | COL2 |
  | :--: | :--: |
  |  W   |  2   |
  |  X   |  2   |
  |  Y   |  3   |
  |  Z   |  4   |

  **[R2]**

  | COL2 | COL3 |
  | :--: | :--: |
  |  1   |  P   |
  |  2   |  Q   |

  ```sql
  SELECT * FROM R1 FULL OUTER JOIN R2 ON R1.COL2 = R2.COL2;
  ```

  **[결과]**

  | R1.COL1 | R1.COL2 | R2.COL2 | R2.COL3 |
  | :-----: | :-----: | :-----: | :-----: |
  |    W    |    2    |    2    |    Q    |
  |    X    |    2    |    2    |    Q    |
  |    Y    |    3    |  NULL   |  NULL   |
  |    Z    |    4    |  NULL   |  NULL   |
  |  NULL   |  NULL   |    1    |    P    |

   </details>

### (4) 왼쪽 외부 조인(Left Outer Join)

- 왼쪽 테이블(R1)의 모든 데이터가 기준
- 일치하는 데이터가 없으면 오른쪽(R2) 컬럼이 NULL로 채워짐

- 예시
  <details>

  **[R1]**

  | COL1 | COL2 |
  | :--: | :--: |
  |  W   |  2   |
  |  X   |  2   |
  |  Y   |  3   |
  |  Z   |  4   |

  **[R2]**

  | COL2 | COL3 |
  | :--: | :--: |
  |  1   |  P   |
  |  2   |  Q   |

  ```sql
  SELECT * FROM R1 LEFT OUTER JOIN R2 ON R1.COL2 = R2.COL2;
  ```

  **[결과]**

  | R1.COL1 | R1.COL2 | R2.COL2 | R2.COL3 |
  | :-----: | :-----: | :-----: | :-----: |
  |    W    |    2    |    2    |    Q    |
  |    X    |    2    |    2    |    Q    |
  |    Y    |    3    |  NULL   |  NULL   |
  |    Z    |    4    |  NULL   |  NULL   |

  </details>

### (5) 오른쪽 외부 조인(Right Outer Join)

- 오른쪽 테이블(R2)의 모든 데이터가 기준
- 일치하는 데이터가 없으면 왼쪽(R1) 컬럼이 NULL로 채워짐

- 예시
  <details>

  **[R1]**

  | COL1 | COL2 |
  | :--: | :--: |
  |  W   |  2   |
  |  X   |  2   |
  |  Y   |  3   |
  |  Z   |  4   |

  **[R2]**

  | COL2 | COL3 |
  | :--: | :--: |
  |  1   |  P   |
  |  2   |  Q   |

  ```sql
  SELECT * FROM R1 RIGHT OUTER JOIN R2 ON R1.COL2 = R2.COL2;
  ```

  **[결과]**

  | R1.COL1 | R1.COL2 | R2.COL2 | R2.COL3 |
  | :-----: | :-----: | :-----: | :-----: |
  |    W    |    2    |    2    |    Q    |
  |    X    |    2    |    2    |    Q    |
  |  NULL   |  NULL   |    1    |    P    |

  </details>

### (6) 곱집합(Cross Join)

- 조인 조건 없이 두 테이블의 모든 행을 조합함
- 결과 행 수 = 테이블1 행 수 x 테이블2 행 수
- 카테시안 곱(Catesian Product)이라고도 함
- 예시
  <details>
  **[R1]**

  | COL1 | COL2 |
  | :--: | :--: |
  |  W   |  2   |
  |  X   |  2   |
  |  Y   |  3   |

  **[R2]**

  | COL2 | COL3 |
  | :--: | :--: |
  |  1   |  P   |
  |  2   |  Q   |

  ```sql
  SELECT * FROM R1 CROSS JOIN R2;
  ```

  **[결과]**

  | R1.COL1 | R1.COL2 | R2.COL2 | R2.COL3 |
  | :-----: | :-----: | :-----: | :-----: |
  |    W    |    2    |    1    |    P    |
  |    W    |    2    |    2    |    Q    |
  |    X    |    2    |    1    |    P    |
  |    X    |    2    |    2    |    Q    |
  |    Y    |    3    |    1    |    P    |
  |    Y    |    3    |    2    |    Q    |

  </details>

### (7) 세타 조인(Theta Join)

- 두 테이블 간 조인 조건을 비교 연산자로 지정하는 조인 방식
- 사용 가능한 연산자: =, >, <, >=, <=, !=
- 내부 조인, 자연조인도 세타 조인의 일부임
