# 집계 함수 & GROUP BY

## 1. 집계 함수의 개념

- 여러 행(Row)의 값을 모아 하나의 결과값으로 계산하는 함수
- SELECT 절에서 사용되며, 보통 GROUP BY 절과 함께 사용됨
- 집계 함수는 NULL 값을 계산에서 제외함

## 2. 주요 집계 함수

| 함수  | 설명                  |
| :---: | :-------------------- |
| COUNT | 행의 개수를 계산한다. |
|  SUM  | 합계를 계산한다.      |
|  AVG  | 평균을 계산한다.      |
|  MAX  | 최댓값을 계산한다.    |
|  MIN  | 최솟값을 계산한다.    |

## 3. GROUP BY의 개념

- GROUP BY는 같은 값을 가진 행들을 그룹으로 묶어 집계 함수와 함께 결과를 행성하는 절임
- SELECT 절에는 GROUP BY 에 사용된 컬럼 또는 집계 함수만 사용이 가능함
- `WHERE → GROUP BY → HAVING → SELECT → ORDER BY` 순으로 실행됨

## 4. 집계 함수 및 GROUP BY 예제

<details>

[학생]

| 학번 | 이름 | 전공 | 점수 |
| :--: | :--: | :--: | :--: |
|  1   | Kim  | 국사 |  90  |
|  2   | Park | 수학 |  80  |
|  3   | Han  | 국사 |  95  |
|  4   | Choi | 수학 |  70  |
|  5   | Lee  | 국사 |  85  |

### (1) 전체 집계 예제(GROUP BY 없음)

```sql
SELECT
  MAX(점수) AS 최고점,
  MIN(점수) AS 최저점,
  SUM(점수) AS 합계
FROM 학생;
```

[결과]

| 최고점 | 최저점 | 합계 |
| :----: | :----: | :--: |
|   95   |   70   | 420  |

### (2) 그룹별 집계 예제(GROUP BY 사용)

```sql
SELECT
  전공, AVG(점수) AS 평균점수
FROM 학생
GROUP BY 전공;
```

[결과]

| 전공 | 평균점수 |
| :--: | :------: |
| 국사 |    90    |
| 수학 |    75    |

### (3) 그룹별 행 개수 구하기

```sql
SELECT
  전공, COUNT(*) AS 학생수
FROM 학생
GROUP BY 전공;
```

[결과]

| 전공 | 학생수 |
| :--: | :----: |
| 국사 |   3    |
| 수학 |   2    |

### (4) HAVING 절 사용하기(그룹 조건)

```sql
SELECT 전공, AVG(점수) AS 평균점수
FROM 학생
GROUP BY 전공
HAVING AVG(점수) >= 80;
```

[결과]

| 전공 | 평균점수 |
| :--: | :------: |
| 국사 |    90    |

### (5) GROUP BY + ORDER BY(정렬 포함) 

```sql

SELECT 전공, AVG(점수) AS 평균점수
FROM 학생
GROUP BY 전공
ORDER BY 평균점수 ASC;
```

[결과]

| 전공 | 평균점수 |
| :--: | :------: |
| 수학 |    75    |
| 국사 |    90    |

</details>
