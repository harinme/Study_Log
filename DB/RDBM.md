# 관계 데이터베이스 모델(RDBM)

## 관계 데이터 모델

- 릴레이션 구조: 속성, 튜플, 도메인, 차수, 카디널리티
- 릴레이션
  - 릴레이션 스키마: 릴레이션의 구조
  - 릴레이션 인스턴스: 실제로 저장된 데이터 조합

## 키(Key)

- 슈퍼키, 후보키(기본키, 대체키), 외래키
- 유일성, 최소성

## 데이터베이스 무결성

- 개체 무결성: 기본키는 NULL 을 가질 수 없고, 중복되지 않는다
- 참조 무결성: 외래키는 NULL이거나, 참조하는 릴레이션에 값이 있어야 함
- 도메인 무결성: 속성 값은 정의된 도메인에 속해야 함
- 고유 무결성: 중복되지 않은 값이어야 함
- 키 무결성: 릴레이션에는 키가 있어야 함
- 릴레이션 무결성: 연산이 릴레이션의 무결성을 해치치 않아야 함
