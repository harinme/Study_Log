# 병행 제어와 데이터 전환

## 병행제어

- 문제점: 갱신 분실, 비완료 의존성, 모순성, 연쇄 복귀
- **병행제어 기법** \* : 로킹, 2단계 로킹, 타임스탬프, 낙관적 병행제어, 다중 버전 병행제어

## 회복

- 장애 유형: 트랜잭션 장애, 시스템 장애, 미디어 장애
- 회복 기법
  - **로그 기반 회복 기법(지연 갱신- REDO, 즉시 갱신-REDO+UNDO)** \*
  - 검사점 회복 기법
  - 그림자 페이징 회복 기법
  - 미디어 회복 기법

## ETL

- 기능: 추출, 변환, 적재
- 품질 관리 대상: 데이터 값, 데이터 구조, 데이터 관리 프로세스
