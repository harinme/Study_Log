# DML(Data Manipulation Language)

## 1. DML

### (1) DML의 개념

- 데이버베이스 내 테이블에 저장된 데이터를 조회, 추가, 수정, 삭제학 위해 사용하는 명령어
- 사용자가 가장 많이 사용하는 SQL 문장이며, 데이터 조작을 위해 필수적으로 사용됨

### (2) DML의 종류

- SELECT
  - 테이블의 데이터를 조회
- INSERT
  - 테이블에 새로운 데이터를 추가
- UPDATE
  - 기존 데이터를 수정
- DELETE
  - 데이터를 삭제

## 2. 조작 방법

### (1) INSERT - 데이터 삽입

```SQL
-- 기본 문법(특정 컬럼에만 값을 넣을 수도 있음)
  INSERT INTO 테이블명 (컬럼1, 컬럼2, …) VALUES (값1, 값2, …);

--  모든 컬럼의 값을 다 넣는 경우 컬럼명 생략 가능(갑의 순서가 일치해야함)
```

- 테이블에 새로운 행(Row)을 삽입
- 지정한 컬럼만 넣을 수도 있고, 모든 컬럼에 데이터를 넣을 수도 있음
- 다른 테이블의 조회 결과를 이용해 데이터를 삽입할 수도 있음

- INSERT SELECT(조회 결과로 다중 행 삽입)
  - ```SQL
      <!-- 다른 테이블의 조회 결과를 이용해 데이터 삽입 -->
      INSERT INTO 테이블명 (컬럼1, 컬럼2, …)
      SELECT 컬럼1, 컬럼2, … FROM 다른 테이블 WHERE 조건;
    ```

### (2) SELECT - 데이터 조회

```SQL
  -- (* 전체 컬럼) 테이블의 모든 컬럼 조회
  SELECT * FROM 테이블명;
```

- 테이블에서 원하는 데이터를 조회
- `WHERE, GROUP BY, HAVING, ORDER BY` 등 다양한 절과 함께 사용해 복잡한 조건 검색 가능
- 필요한 컬럼만 선택적으로 조회 가능

- 조건을 이용한 조회(WHERE)
  - ```SQL
      SELECT 컬럼1, 컬럼2, …, FROM 테이블명 WHERE 조건;
    ```

- 정렬을 이용한 조회(ORDER BY)
  - 정렬 컬럼 기준으로 오름차순 혹은 내림차순 정렬
  - ```SQL
      <!-- 기본은 오름차순 ASC(오름차순)/ DESC(내림차순) -->
      SELECT 컬럼1, 컬럼2, …, FROM 테이블명 ORDER BY 정렬 컬럼 [ASC|DESC];
    ```

### (3) UPDATE - 데이터 수정

```SQL
  -- 필요한 행만 선택하여 수정(WHERE 생략 시 전체 행 수정)
  UPDATE 테이블명 SET 컬럼 = 값 [, 컬럼 = 값 …] WHERE 조건;
```

- 기존 데이블의 데이터를 수정
- WHERE 절이 없으면 전체 행이 수정되므로 주의해야함
- 여러 컬럼을 한번에 수정 가능

### (4) DELETE - 데이터 삭제

```SQL
  -- 조건에 맞는 행만 선택하여 삭제(WHERE 생략 시 전체 행 삭제)
  DELETE FROM 테이블명 WHERE 조건;
```

- 테이블에서 특정 조건을 만족하는 행(Row)을 삭제
- WHERE 절이 없으면 전체 데이터 삭제
- **테이블 구조는 유지되고 데이터만 제거**
