# 선행처리기

## 1. 선행 처리기

### (1) 선행 처리기의 개념

- 컴파일 이전 단계에서 프로그램 상단에 선언된 지시자(Directive)를 처리하는 역할을 수행하는 도구
- 컴파일러가 실제로 소스 코드를 번역하기 전에 선행 처리기가 특정 작업을 수행하여 최종적으로 컴파일러가 처리할 코드를 준비함

### (2) 주요 기능

1. 매크로 처리
   - 코드에서 반복적으로 사용되는 값을 정의하거나 간단한 코드 조각을 매크로롤 정의하여 사용
   - ex: `#define PI 3.14592`

2. 파일 포함
   - 다른 파일을 현재 소스 코드에 포함시키는 역할
   - ex: `#include <stdio.h>` 는 표준 입출력 라이브러리 파일을 포함

3. 조건부 컴파일
   - 특정 조건에 따라 코드의 일부를 포함하거나 제외

4. 문자열 치환
   - 매크로로 정의된 심볼 이름을 해당 값으로 치환
   - ex: `#define SQUARE(x)((x)*(x))`

## 2. 매크로

### (1) 매크로의 개념

- 선행 처리기에서 `#define`을 사용하여 단순 치환되는 자료를 말함
- 프로그램 작성 시 명령이나 수식 또는 상수값이 자주 사용될 때 정의하여 사용

### (2) 매크로의 종류

1. 매크로 상수

- 미리 정의한 매크로 상수명이 프로그램에서 사용되면 매크로 확장 문자열로 치환함
- ex: `define N 10`

2. 매크로 함수
   - 전달되 인자의 형태를 가지고 치환하는 동작을 함
   - ex: `SQR(x)x\*x`
