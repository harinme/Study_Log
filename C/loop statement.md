# 반복문

## (1) for 문

- 반복 횟수가 정해진 경우에 가장 적합한 반복문으로, 초기식, 조건식, 증감식을 포함하는 구조

1. 구조

   ```C
   for(초기식; 조건식; 증감식)
   {
     //반복 실행할 코드
   }
   ```

   - 초기식
     - 반복문이 시작되기 전에 한번만 실행
     - 반복 제어 변수의 초기값 설정
     - ex) `int i = 0` (i를 0으로 초기화)
   - 조건식
     - 반복 여부를 결정
     - 조건식이 참(True)이면 본문 실행, 거짓(False)이면 반복문을 종료
     - ex) `i < 10` (i가 10보다 작을 때만 실행)
   - 증감식
     - 반복 제어 변수의 값을 변화시킴
     - 반복이 끝날 때마다 실행됨
     - ex) i++ (i를 1 증가)
     - **반복문의 증감식은 `i++. ++i` 모두 같음**

## (2) while 문

- 특정 조건을 만족할 때까지 반복 실행하는 반복문
- 조건식이 참(True)일 때 계속 실행된다.
- 반복 횟수가 사전에 정해지지 않은 경우에 적합됨

1. 구조

   ```C
   while(조건식)
   {
     //반복 실행할 코드
   }
   ```

   - 조건식
     - 반복 여부를 결정
     - 조건식이 참(True)이면 본문 실행, 거짓(False)이면 반복문을 종료
     - ex) `x > 0` (x가 0보다 클 때 반복 실행)

   - 본문
     - 조건식이 참인 경우 실행되는 명령문 블록
     - 본문 실행 후 조건식이 다시 평가됨

## (3) do ~ while 문

- 무조건 한 번 반복을 실행한 후 조건식을 검사하여 조건이 참(True)일 때 반복 실행
- 조건식이 거짓(False)이더라도 최소 한 번은 본문이 실행됨

1. 구조

   ```C
    do{
      //반복 실행할 코드
    }while(조건식);
   ```

   - 본문
     - 반복문 실행 시 항상 처음 한번은 실행
     - 조건식 검사 여부와 관계없이 무조건 실행됨

   - 조건식
     - 본문 실행 후 조건을 평가
     - 조건식이 참(True)이면 반복 실행, 거짓(False)이면 반복문을 종료
     - ex) `x > 0` (x가 0보다 크면 반복 실행)

## (4) continue 문

- 반복문의 나머지 코드를 건너뛰고 바로 다음 반복으로 이동
- continue 문 아래에 있는 명령문은 실행되지 않고, 반복문의 조건 확인으로 돌아감

1. 구조

   ```C
     for(초기식; 조건식; 증감식){
      if(조건){
         continue;
      }
      // 이 부분은 조건을 만족하면 실행되지 않음
   }
   ```

## (5) break 문

- 반복문이나 switch 문에서 실행 흐름을 즉시 종료시킴
- 반복문 내에서 break를 만나면 반복문이 종료되고, 반복문 이후의 명령문이 실행됨

1. 구조

   ```C
     for(초기식; 조건식; 증감식){
      if(조건){
        break; // 조건이 참일 때 반복문 종료
      }
      // 이 부분은 break를 만나지 않은 경우에만 실행
   }
   ```
