# 함수와 변수의 유효 범위

## 함수

### (1) 함수의 정의

- 반복적으로 수행해야하는 작업을 정의해 놓은 작은 프로그램 단위
- 코드의 재사용성과 가독성을 높이기 위해 사용됨

### (2) 함수 선언

- 함수는 사용 전에 선언(프로토타입)하거나 정의하여야 한다
- ```c
  //본 형태
  반환형 함수명(매개 변수 목록){

  // 예제
  int add(int a, int b){
    // 처리할 내용
  }
    }
  ```

### (3) 함수의 종료

1.  사용자 정의 함수
    - 사용자가 구현하고자 하는 특정 기능을 정의한 함수
    - 변수명처럼 명명 규칙을 따라 이름을 정의하며, 함수의 역할을 잘 나타내는 이름을 사용
2.  표준 함수(라이브러리 함수)
    - C 언어의 표준으로 제공되는 기능과 사용법이 정의된 함수
    - 라이브러리에 포함되어 있으며, 필요한 경우 `#include` 지시문으로 호출해 사용한다.

### (4) 자료의 전달 방법

1. 값에 의한 호출(Call by Value)
   - 함수 호출 시 값을 복사하여 전달하는 방식
   - 전달된 변수의 값을 함수의 매개변수에 복사하여 사용
   - 원본 변수와 복사된 변수는 별개의 메모리 공간을 사용
   - 함수 내에서 매개 변수의 값을 변경해도 원본 변수에는 영향을 미치지 않음

2. 참조에 의한 호출(Call by Reference)
   - 함수 호출 시 변수의 주소값을 전달하는 방식
   - 전달된 주소값을 사용하므로, 함수에서 원본 변수의 값을 직접 수정이 가능함
   - 전달된 변수와 매개변수의 값는 같은 메모리 공간을 참조
   - 함수 내에서 매개 변수의 값을 변경하면 원본 변수도 영향을 받음

## 변수의 유효 범위

### (1) 변수의 유효 범위의 개념

- 변수가 프로그램 내에서 참조할 수 있거나 유효한 범위
- C언어에서는 변수가 선언된 위치에 따라 접근 가능 여부가 달라짐

### (2) 변수의 종류와 유효 범위

1. 지역 변수(Local Variable)
   - 함수 또는 블록 내부에서 선언된 변수
   - 해당 블록 내에서만 유효하며, 블록이 종료되면 메모리에서 지워짐
   - 동일한 이름의 변수를 다른 블록에서 사용 가능

2. 전역 변수(Global Variable)
   - 함수 외부에서 선언된 변수
   - 프로그램 전체에서 접근이 가능하며, 모든 함수에서 공유됨
   - 프로그램이 종료될 때까지 메모리에 유지됨

3. 정적변수(Static Variable)

- static 키워드로 선언된 변수
- 선언된 블록 내에서만 유효하지만, 프로그램이 종료될 때까지 메모리에 유지됨
- 초기화 값은 프로그램 실행 중 한번만 설정됨
- 값을 유지하며, 다음 호출 시 이전의 값이 그대로 남아있음

4. 매개변수(Parameter Variable)
   - 함수 호출 시 전달된 값을 저장하는 임시 변수
   - 함수 내부에서만 유효하며 함수가 종료되면 메모리에서 소멸됨

## 재귀함수

### (1) 재귀함수의 정의

- 함수 내부에서 자기 자신을 다시 호출하는 함수
- 문제를 반복적으로 처리하며, 호출된 함수는 스택 메모리에 차곡차곡 쌓인 뒤 반환 과정을 통해 처리함

### (2) 재귀함수의 특징

- 반드시 종료 조건이 있어야 함
- 종료 조건이 없으면 무한 호출로 스택 오버플로우(Stack Over Flow)가 발생함
- 함수가 자기 자신을 호출하며, 매번 호출할 때 입력값이 변해야 함
  일반적으로 호출 과정에서 문제를 더 작게 나누어 처리
  함수 호출 시 스택 메모리에 호출 정보를 저장
  모든 호출이 끝나면 스택에서 호출 정보를 하나씩 꺼내며 반환

### (3) 재귀함수의 장단점

- 장점
  - 코드가 간결하며, 복잡한 문제를 논리적으로 쉽게 구현 가능
  - 트리 탐색이나 분할 정복 문제 같은 경우 매우 유용함
- 단점
  - 호출마다 스택 메모리를 사용하므로 깊은 호출은 메모리 사용량이 커짐
  - 반복문으로 해결이 가능한 문제는 재귀를 사용하면 성능이 떨어질 수 있음
  - 잘못된 설계로 스택 오버플로우 위험이 있음
