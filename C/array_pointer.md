# 배열 & 포인터

## 배열

### (1) 배열의 개념

- 동일한 자료형으로 이루어진 물리적으로 연속된 메모리 공간
- 구성요소
  - 배열 요소: 배열을 구성하는 각각의 값
  - 인덱스: 배열 요소의 위치를 나타내는 숫자

### (2) 베열의 선언

> ### **int a [5]** <자료형 배열명 [개수]>
>
> | a[0] | a[1] | a[2] | a[3] | a[4] |
> | :--: | :--: | :--: | :--: | :--: |
> |  -   |  -   |  -   |  -   |  -   |

## 포인터 변수

### (1) 포인터 변수의 개념

- 변수의 메모리 주소를 저장하는 변수
- 포인터를 사용하면 특정 변수의 메모리 공간에 직접 접근 가능
- 값을 저장하는 대신 메모리 주소를 저장하여 주소에 있는 데이터를 참조하거나 수정할 수 있음

### (2) 포인터 변수의 선언과 초기화

1. 포인터 변수 선언

- 자료형 뒤에 \*를 붙여 선언
- ```C
  int * ptr; // int형 데이터를 가리키는 포인터 변수 ptr 선언
  ```

2. 포인터 변수 초기화

- 변수의 주소를 저장하여 초기화한다
- ```C
  int a = 10;
  int * ptr = &a; // 변수 a의 주소를 ptr에 저장
  ```

### (3) 포인터 변수의 기본 동작

1. 주소 연산자(&)
   - 변수의 메모리 주소를 구할 때 사용
   - ```C
      int a = 10;
      int * ptr = &a; // 변수 a의 주소를 ptr에 저장
     ```

2. 역참조 연산자(\*)
   - 포인터가 가리키는 주소의 값을 참조하거나 수정할 때 사용
   - ```C
     int a = 10;
     int * ptr = &a; // 변수 a의 주소를 ptr에 저장
     printf("%d₩n", *ptr; // ptr이 가리키는 값 출력)
     ```

### (4) 포인터 변수의 특징

- 포인터는 변수의 주소를 저장
- 포인터를 사용하면 변수를 간접적으로 참조할 수 있음
- 포인터는 자료형에 따라 선언되어야 함

## 3. 1차원 배열과 포인터

### (1) 1차원 배열과 포인터의 기본 개념

- 1차원 배열은 `동일한 자료형의 데이터`가 메모리상 `연속적`으로 저장된 구조
- 배열의 이름은 배열의 첫번째 요소를 가리키는 주소 상수로 사용됨
- 따라서 배열명은 포인터처럼 동작하며, 포인터 연산을 통해 배열 요소에 접근할 수 있음
- 배열은 선언 시 크기를 변경할 수 없지만, 포인터는 다른 메모리를 가리키도록 변경할 수 있다

### (2) 1차원 배열과 포인터의 관계

- 배열명은 첫번째 요소의 주소와 동일한 의미를 가짐
- arr 과 &arr[0]은 같은 주소이며, arr+i는 &arr[i] 와 같음
- 배열 요소 접근 방식
  - 인덱스 방식: `arr[i]`
  - 포인터 방식: `*(arr + i)`

### (3) 배열명과 포인터의 비교

|       구분        |        배열명        |         포인터 변수         |
| :---------------: | :------------------: | :-------------------------: |
|       의미        | 첫 번째 요소의 주소  | 어떤 메모리를 가리키는 변수 |
| 값 변경 가능 여부 | 변경 불가(주소 상수) |    다른 주소로 변경 가능    |
|     산술 연산     |   가능 (`arr + 1`)   |       가능 (`ptr++`)        |
|   선언 시 크기    |         고정         |            없음             |

## 4. 포인터 배열

### (1) 포인터 배열의 개념

- 배열의 요소가 포인터(메모리 주소)로 이루어진 배열
- 배열의 각 요소가 변수나 다른 데이터 구조를 가리키는 주소를 저장함
- 포인터 배열은 다차원 배열, 문자열 배열, 함수 포인터 등 다양한 상황에서 활용됨

### (2) 포인터 배열의 선언과 초기화

- 선언: 자료형 \* 배열명[크기];
- ```C
  int a = 10, b = 20, c = 30;
  int * arr[3] = { &a, &b, &c };
  ```

## 5. 2차원 배열

### (1) 2차원 배열의 개념

- 행(Row)과 열(Column)로 구성도니 배열로, 배열 안에 또 다른 배열이 존재하는 형태
- 동일한 자료형으로 이루어진 행렬(Matrix) 구조를 저장하기 위해 사용됨
- 물리적으로 연속된 메모리 공간에 저장되며, `arr[행][열]` 형태로 접근

### (2) 2차원 배열의 선언

1. 2차원 배열의 선언

- 자료형 배열명[행][열];

1. 2차원 배열 초기화

- 행별로 구분한 초기화
  - ```C
      int a[3][3] = {
        {1, 2, 3}, {4, 5, 6,}, {7, 8, 9}
      };
    ```

- 중괄호를 생략한 일렬 초기화
  - ```C
      int a[3][3] = {
      1, 2, 3, 4, 5, 6, 7, 8, 9
      };
    ```

- 부분 초기화
  - ```C
      int a[3][3] = {
        {1, 2}, // 나머지 1개는 자동 0
        {3}, // 나머지 2개 자동 0
        4 // arr[2][0] =4, 나머지 2개 자동 0
      }
    ```

## 6. 배열 포인터

### (1) 배열 포인터의 개념

- 배열의 시작 주소를 저장할 수 있는 포인터이다
- 배열의 전체를 가리키는 포인터로, 단일 요소가 아닌 배열 자체를 대상으로 함
- 배열의 크기와 자료형을 고정적으로 가리키는 특징이 있음

### (2) 배열 포인터의 선언과 사용

1. 배열 포인터 선언
   - 자료형(\*포인터명)[배열 크기];
   - ex: `int(*ptr)[3];`

2. 배열 포인터 초기화
   - 배열의 시작 주소를 저장하여 초기화한다
   - ```C
      int arr[3] = {10, 20, 30};
      int (*ptr)[3] = &arr;
     ```

## 7. 이중 포인터

### (1) 이중 포인터의 개념

- 포인터를 가리키는 포인터
- 즉, 포인터 변수의 주소를 저장하는 포인터이며, \* 연산을 두번 사용하여 최종 데이터에 접근함
- 다차원 배열, 동적 메모리 할당, 함수에서 포인터를 수정할 때 주로 사용됨
- 한 번의 역참조(\*)는 포인터 값(주소)을 읽고, 두 번의 역참조(\*\*)는 실제 데이터에 접근함

### (2) 이중 포인터의 선언과 초기화

1. 이중 포인터 선언
   - 자료형 \*\* 포인터명;
   - `int **pp;`

2) 이중 포인터 초기화
   - 포인터 변수의 주소를 저장하여 초기화함
   - ```C
      int a = 10;
      int *p = &a; // p는 a를 가리킴
      int **pp = &p; // pp는 p를 가리킴
     ```
