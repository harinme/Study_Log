# 제어문

## (1) if

1. 단순 if 문

   ```C
   if (조건) {
   // 조건이 참일 때의 처리;
    }
   ```

2. if~else 문

   ```C
   if (조건) {
   // 조건이 참일 때의 처리;
   }
   else{
    // 조건이 거짓일 때의 처리;
   }
   ```

3. 다중 if문
   ```C
   if (조건1) {
   // 조건1이 참일 때의 처리;
   }
   else if(조건2){
    // 조건2이 참일 때의 처리;
   }
   else if(조건3){
    // 조건3이 참일 때의 처리;
   }
   else{
    // 모든 조건이 만족하지 않을 때의 처리
   }
   ```

## (2) switch

1. 문법

   > break를 만나기 전까지 밑으로 쭉 내려가면서 실행

   ```c
   switch(변수){
     case 값1:
       명령문;
       break;
     case 값1:
       명령문;
       break;
     default: // 변수랑 상관없이 실행
       명령문;
   }

   ```
